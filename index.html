Foundry Recipe Data

Versioned JSON data of the game Foundry, served for community tools. Documentation: README on GitHub.

  • v1/index.json – foundry-data v1 (items, fluids, recipes with per-machine rates, machines, research, assembly line, localization)
  • index.json – legacy format (recipes_clean.json, machines.json, …)
